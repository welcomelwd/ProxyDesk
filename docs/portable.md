# ProxyDesk Windows x64 便携版

完整解压 ZIP 后，双击 `ProxyDesk.exe`。内置 .NET 运行时和 WinDivert 驱动，不再附带或加载 DNS 注入组件。

## 启动和退出

- 本机没有 ProxyDesk 后台运行时，启动会申请 Windows 管理员授权。确认后，窗口以普通用户权限运行，网络后台以临时管理员进程运行；不注册 ProxyDesk Windows 服务。
- UAC 提示需本人确认；取消后可在设置中重新点击“授权启动后台”。WinDivert 在启用时仍会按官方方式注册和加载内核驱动，便携版不能免除这个权限要求。
- 本机已有 ProxyDesk 后台时，直接连接现有后台，使用其已有配置和数据目录。界面底部和设置的关于页显示实际连接方式与配置目录。安装版和便携版共用网络接管入口，同一时间使用一个后台。
- 关闭窗口会进入托盘。请在托盘选择“退出并停止代理”；独立运行的便携后台随之退出，已接管程序恢复系统 DNS。复用安装版后台时只停止代理，Windows 服务继续运行。
- 放在当前用户可写的目录中使用，例如文档目录；请先解压，不要在 ZIP 预览中直接运行。

## 配置和迁移

独立运行时，配置、代理凭据及授权结果保存在程序旁的 `Data` 文件夹。首次使用自动创建默认直连的 `General` 配置，不附带个人代理、规则或日志。

移动到同一台电脑的新目录时，连同 `Data` 一起移动。更新时先退出程序，将新版解压到新目录，再复制旧 `Data` 文件夹。从注入版升级时，旧进程可能仍占用旧 DNS 组件文件，关闭这些应用后再删除旧目录。

密码使用 Windows DPAPI 加密，无法保证跨电脑或 Windows 账户解密。迁移到另一台电脑时，使用设置中的配置导出和导入，再重新填写代理密码、绑定程序路径。

DNS 代理仅覆盖应用自身发出的、归属明确的普通查询；Windows 公共 DNS 服务代发的查询继续使用系统 DNS，应用自带 DoH/DoT 按普通流量规则处理。Linux 便携包不属于本次交付。
